HOW TO PREVIEW
--------------
Double-click index.html on a computer. It should open in your web browser.

WHAT TO EDIT FIRST
------------------
1. Open script.js in a text editor.
2. Put the real URLs for your YouTube, Instagram, TikTok, X, and Twitch profiles
   into the socialLinks section.
3. Edit the "Play as a Pet" copy in index.html whenever you want.
4. Replace the mascot image later if you make a final logo.
